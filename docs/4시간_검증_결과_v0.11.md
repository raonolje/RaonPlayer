# Raon Local Player v0.11 · 4시간 검증 결과

**2026-10-24, 시도 13에서 동일 Windows 패키지로 큐 전환 2시간과 루프 2시간을 모두 통과했습니다.** 실제 재생 측정 합계는 14401.9141초입니다. 사전 검사·준비·스크린샷·종료 시간은 이 합계에 넣지 않았습니다. 이후 기능·오류 대응 검사도 통과했습니다. 앞선 실패 기록은 삭제하지 않았습니다.

## 측정 결과

1920×1080 / 60fps 합성, 실제 1080p60 영화와 알파 영상 3개, 네이티브 출력 창 10개, 큐 1,004개 조건입니다. 큐 단계에서는 60fps 영화와 24fps 알파 소스를 교대로 전환합니다. 운영 창 1초 정지·대량 화면 배치·자동 저장을 반복했습니다. 모든 간격·작업 지연은 100ms 미만, 검은 화면·누락·GPU 오류는 0이어야 합니다.

- 색상 표본 검사 72,011회에서 검은 화면 0, 캐시 순서 누락·텍스처 불일치·출력 순서 누락·GPU 오류 0입니다. 색상은 12틱마다 검사하므로 모든 프레임의 픽셀을 검증한 것은 아닙니다.

- PVW는 대기 소스가 바뀌지 않을 때 약 1.9초의 ACK 간격이 기록됩니다. 이는 기존 검사 설계상 유휴 미리보기이며 표의 재생 출력 간격에서 제외합니다. PVW 작업별 지연은 각각 6.3/6.7ms 이하로 별도 검사했습니다. 출력 수 10개와 ACK 진행 여부는 유지했습니다.
- 각 단계 마지막 HOLD에서 모든 대기 출력이 같은 최종 프레임까지 완료됐으며, BLACK·미리보기 해제 후 CPU/GPU 캐시 예약량은 각각 0입니다.
- 후속 실제 영화 1,000회 CUT에서 검은 화면 0, 합성 최대 간격 77.6ms입니다. 준비까지 포함한 최대 292ms는 재생 공백과 구분합니다. GPU 손실·Worker 정지 주입 검사의 의도한 오류는 정상 재생 검사와 별도입니다.

## 변경과 실패 이력

v0.6은 비동기 WebGL2 펜스, v0.7은 텍스처 저장 공간 재사용을 추가했습니다. v0.8은 실제 추적에서 확인된 원시 영상 업로드 중 지연 디코딩을 피하도록 I420/I420A 평면 업로드와 YUV/알파 셰이더 변환을 적용했습니다. 색상·크로마 경계·알파 비교 차이는 채널당 0–1이며, 색이 달랐던 중간 RGBA 후보는 폐기했습니다.

v0.9은 Ready 상태로 기다리던 재생 프로세스에 한해 Windows High 우선순위를 적용했습니다. 운영 창·메인·다른 앱은 변경하지 않았습니다. 이후 별도 실패에서 공유 GPU 서비스의 DXGI Present 대기가 확인됐습니다. v0.10의 DirectComposition 전체 비활성화는 지속적인 출력 지연을 유발해 제외했습니다. v0.11은 DirectComposition을 유지하고 기본 화면에 Chromium BufferQueue 기능을 사용합니다. 사전 검사 보존 추적에는 문제의 DXGI Present가 0회였습니다. BufferQueue 이름의 이벤트는 0회여서 그 이벤트만으로 내부 경로 전체를 증명하지 않습니다. 옵션 적용·하드웨어 가속과 실제 장시간 성능 결과를 함께 확인했습니다. 모든 과거 실패가 하나의 원인이었다는 결론은 내리지 않습니다.

## 배포·한계

시험 시작/최종/회귀 검사 ASAR와 실행 소스 해시가 일치합니다. 최종 ASAR SHA-256: `352bacda4aa0fed6a67ccdfebe434e398b03edf927e1a9b21738ea3bd3ce7e99`. 최종 시험 후 런타임 재빌드는 하지 않았습니다. Windows·소스·증거 ZIP은 CRC 검사 후 제공합니다.

Win11 / Core Ultra 9 285K / 약 127GiB RAM / NVIDIA RTX PRO 6000 Blackwell의 ANGLE D3D11 하드웨어 WebGL 환경입니다. 사용자 다른 앱은 종료하지 않았습니다. FFmpeg/FFprobe는 별도 설치가 필요하며 현재 PC의 C:\ffmpeg\bin을 사용했습니다.

**10개 창은 물리 출력 장치 10대가 아닙니다. 8K60, HDMI/SDI 신호 드롭, 물리 장치 10대, 젠록·프레임록, 실제 오디오 장치의 A/V 동기는 측정하지 않았습니다.** 이번 특정 환경의 4시간 통과이며 모든 시스템의 무중단 보장은 아닙니다. MOGRT 기능은 이 원본에 포함하지 않고 별도 앱으로 후속 개발합니다.
